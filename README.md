# Reshapyx

Небольшой сервис на FastAPI и Pillow для обработки изображений: получение
характеристик, изменение размера с сохранением пропорций и конвертация
между PNG, JPEG и WebP. Для разработчиков и всех, кому нужно быстро
подготовить картинку для сайта.

## Запуск на macOS / Linux

Требуется Python 3.12.

```bash
git clone https://github.com/dangannn/reshapyx.git
cd reshapyx
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app_final:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000/docs, выберите операцию, нажмите **Try it out**,
загрузите изображение и выполните запрос.

Для запуска во время разработки с автоматическим перезапуском:

```bash
python -m uvicorn app_final:app --reload
```

## Тесты

В активированном виртуальном окружении:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -v
```

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `MAX_UPLOAD_MB` | `10` | Максимальный размер файла в МиБ |
| `MAX_IMAGE_PIXELS` | `20000000` | Максимальное количество пикселей изображения |

Настройки читаются при запуске и должны быть положительными целыми числами.

```bash
MAX_UPLOAD_MB=5 python -m uvicorn app_final:app
```

Для настроек из файла скопируйте `.env.example` в `.env` и запустите:

```bash
python -m uvicorn app_final:app --env-file .env
```

Настоящий `.env` исключён из Git; публиковать секреты в нём не нужно.

## Проверка и диагностика

При работающем приложении выполните в другом терминале:

```bash
curl -f http://127.0.0.1:8000/health
curl -f http://127.0.0.1:8000/version
```

Логи запуска и запросов выводятся в терминал с Uvicorn.
Если соединение не устанавливается, проверьте запуск приложения и порт.
Ответ `413` означает превышение лимита файла или пикселей, `422` — неверные
параметры либо неподдерживаемое или повреждённое изображение; причина указана
в поле `detail`. Если порт занят, добавьте к команде запуска `--port 8001`.

## GitHub Actions

Workflow [Tests](https://github.com/dangannn/reshapyx/actions/workflows/ci.yml)
автоматически запускается на каждый **push** и **pull request**.
На Ubuntu с Python 3.12 устанавливаются зависимости и выполняется
`python -m pytest -v`.

После успешных тестов создаётся artifact **reshapyx** с приложением, файлами
зависимостей, тестами и README. Откройте успешный запуск во вкладке **Actions**
и скачайте архив из раздела **Artifacts**. При падении тестов архив не создаётся;
причину можно увидеть в логе шага **Run tests**.
